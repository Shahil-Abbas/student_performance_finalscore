# Student Performance Analysis

Exploratory Data Analysis (EDA) project on student performance data using Python, Pandas, Matplotlib, and Seaborn. This project analyzes various academic, lifestyle, and social factors affecting students' final scores.

---

# Project Overview

The project focuses on analyzing student performance based on:

- Study hours
- Attendance
- Sleep hours
- Stress levels
- Diet quality
- Internet quality
- Extracurricular activities
- Part-time jobs
- Previous GPA

The notebook performs data cleaning, visualization, grade classification, and factor-based analysis to identify patterns influencing academic performance.

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
